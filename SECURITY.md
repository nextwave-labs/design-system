# Security Policy

## Supported versions

The project maintainers aim to support the latest stable versions of the project and the currently active Node.js version used by the repo.

## Reporting a vulnerability

If you believe you have found a security vulnerability in this project, please do not open a public issue.

Please report it privately to the maintainers using the project security contact channel. If this repository is configured with GitHub Security Advisories, use that channel instead.

For a fast response, include:

- a description of the vulnerability
- the affected version or commit
- steps to reproduce
- any proof of concept or suggested fix

## Response expectations

We will review reports as quickly as possible and will do our best to confirm and remediate verified vulnerabilities in a timely manner.

## Public disclosure

We ask that reporters give maintainers a reasonable amount of time to address a vulnerability before publishing details publicly.

This helps protect users and allows a safe fix to be prepared and released.

## Scope

This policy applies to the Flowi library and its repository code. It does not apply to third-party dependencies or downstream consumer applications unless the issue is directly caused by this project.
