# Repository Instructions

All work in this repository must be written in English.

- Use English for source code, identifiers, comments, documentation, examples, Storybook stories, user-facing text, commit messages, pull requests, and issue-related content.
- Do not write Spanish or any other language in new or modified project content.
- When updating existing content, translate any touched non-English text into English rather than preserving or extending it.
- Keep technical names, API names, package names, URLs, and quoted third-party text unchanged when required for correctness.
- Before finishing a task, verify that all newly added or modified text follows this policy.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the canonical contribution guidelines.
